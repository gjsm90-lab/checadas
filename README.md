# Webinar «¿Ya cubriste la nueva ley de checadas?» — landing de registro

Página pública del webinar **Ley de checadas 2027 · CONTPAQi Colabora®** (TFGRUPO, martes 13 de octubre de 2026),
publicada con GitHub Pages desde la rama `main` (raíz): https://gjsm90-lab.github.io/checadas/

- `index.html`: la página. El formulario manda los registros a la aplicación web de Apps Script (`CONFIG.ENDPOINT`),
  que los guarda en la hoja de Google y manda la liga y los recordatorios por Brevo.
- `img/`: logos, imagen para compartir (`og.png`) e imagen de cabecera de los correos (`mail-hero.jpg`).
